# Firstfire — Wolf & War

A mobile settlement-defense prototype by **Alex Wiserax**.

[Play in your browser](https://wiserax.github.io/alex-wiserax-firstfire/)

Ride a wolf, build defenses, choose Arrow / Frost / Bomb tower paths, and collect temporary war-chest powers. Three chapters feature human raiders, an orc war band and frost trolls, with distinct routes and bosses.

**Mobile:** drag in the battlefield to ride. Enter a dashed plot to start construction; the coin stream keeps going when you leave. Tap Upgrades or revisit a built plot to improve it. Tap War Cry to stagger enemies.

**Desktop:** WASD / arrows, Space for War Cry, Escape to pause.

Amber and relic powers reset after a battle. Gold and Ember Shards earned from waves buy permanent rider talents. The Store has training supplies, chapter reward packs and a gold-to-shard exchange. The Talents tab displays a connected upgrade tree. Progress is stored in this browser on this address; the earlier hosting address has a separate save.

`Firstfire.html` is the complete standalone game, including art, fonts, code and procedural audio. Save it and open it in a browser that supports local HTML execution. A phone's document previewer may not run games.

The three-dimensional art and audio are generated in code. Chapter previews reuse the actual animated game models. Relic illustrations are original generated assets. No extracted reference-game code or assets are included. Third-party font and Three.js notices are in `licenses/` and in the bundled HTML.

This is an iterative prototype. Desktop browser viewport checks and game-loop simulations do not establish performance on every phone.
